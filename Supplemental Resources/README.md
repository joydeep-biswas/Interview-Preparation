## Pillar 1: Universal Interview Foundations (Roadmap & Specifications)

These tracks cover the cross-cutting technical evaluations common across all senior and staff-level software engineering interviews:

| Foundation Domain | Scope & Core Competencies | Architectural Curriculum Blueprint |
| :--- | :--- | :--- |
| **Data Structures & Algorithms (DSA)** | Algorithmic patterns, memory footprints, asymptotic complexity, graph traversals, dynamic programming, sliding window, two-pointer techniques, and monotonic stacks. | Follows standard 10-module progression: Array/Strings $\rightarrow$ Linked Lists $\rightarrow$ Trees/Tries $\rightarrow$ Graphs/BFS/DFS $\rightarrow$ Heaps/Greedy $\rightarrow$ Dynamic Programming $\rightarrow$ Backtracking $\rightarrow$ Advanced Math/Bitmask. |
| **System Design (HLD & LLD)** | High-Level Design (distributed consensus, sharding, caching topologies, API rate limiters, CDC, event streaming) & Low-Level Design (SOLID, design patterns, concurrency models, schema modeling). | Follows 10-module progression: Fundamentals & Scalability $\rightarrow$ Storage & Caching $\rightarrow$ Messaging & Queues $\rightarrow$ Consensus & Transactions $\rightarrow$ Canonical High-Scale Systems (URL Shortener, Chat, Feed, Metrics). |
| **Behavioral & Leadership** | Conflict resolution, executive stakeholder management, technical leadership, incident retrospectives, mentoring, and STAR-structured storytelling. | Follows structured framework guides: STAR Method Mastery $\rightarrow$ FAANG/Enterprise Leadership Principles $\rightarrow$ Architectural Failure Post-Mortems $\rightarrow$ Cross-Functional Influence. |
